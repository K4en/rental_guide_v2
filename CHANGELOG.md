# Changelog

All notable changes to this project are documented here.

The project is primarily developed as a learning project, so changes may include both user-facing features and implementation/learning milestones.

## [0.2.0] - Public Guides & Deployment

### Added

- Public guide pages
- Public guide API endpoint
- Automatic public URL generation
- Copy public guide URL functionality
- QR code generation for public guide URLs
- Firebase Hosting deployment for the frontend
- Google Cloud Run deployment for the FastAPI backend
- Docker configuration for the backend

### Improved

- Frontend API configuration for local and production environments
- Separation between authenticated and public API functionality
- Guide retrieval and rendering

## [0.1.0] - Initial Application

### Added

- User registration
- User login
- JWT authentication
- Protected backend endpoints
- Property creation and management
- Property ownership validation
- Guide creation
- Guide editing
- Guide deletion
- Guide retrieval
- React component-based frontend
- React state management
- FastAPI backend
- SQLite database

### Learning Focus

- REST API design
- JavaScript `fetch()` requests

- `useState`
